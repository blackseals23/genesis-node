# Decision-Aligned System Prototype

This repository contains a static GitHub Pages prototype for explaining a decision-aligned AI command system.

The page positions the product around turning a user's working habits, thinking steps, search rules, tradeoff logic, and quality bar into an orchestration layer for AI capabilities.

## Local preview

Open `index.html` in a browser.

The prototype runs entirely in the browser and does not make external API calls.

## Deploying to GitHub Pages

1. Push this repository to GitHub.
2. Open Settings > Pages.
3. Select the `main` branch and `/ (root)` folder.
4. Save the settings.

GitHub Pages will publish the static prototype at the generated Pages URL.
